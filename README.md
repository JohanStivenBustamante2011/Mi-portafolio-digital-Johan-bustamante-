## Mis proyectos
-Feria de la ciencia Levitador acústico:

Este proyecto consistió en crear un prototipo con sensores ultrasónicos que emiten un sonido inaudible para el ser humano. Al superponerse las ondas emitidas, se genera la presión necesaria en los nodos para que pueda flotar un pequeño objeto, como una bola de poliestireno.

Para realizarlo, utilizamos conocimientos sobre ondas ultrasónicas y ondas estacionarias. También implementé la impresión 3D para crear la base donde iban a estar ubicados los transductores ultrasónicos.

En este proyecto aprendí a implementar la impresión 3D y obtuve conocimientos sobre qué son las ondas y cómo se producen las ondas requeridas para generar ondas estacionarias que permiten la levitación de pequeñas pelotas de poliestireno.

-Proyecto empresarial:

Este proyecto consistía en la ejecución de un producto que decidiéramos crear y vender. Utilizamos herramientas como Excel para la organización de las cosas que compramos para la preparación del producto, la organización de los precios y los gastos que íbamos a tener que realizar.

Con este proyecto aprendí sobre la organización de los gastos, el manejo de los precios y la importancia de llevar un control de los recursos utilizados para la elaboración y venta de un producto. También aprendí sobre el proceso que se debe tener en cuenta para organizar y ejecutar una idea de negocio.
